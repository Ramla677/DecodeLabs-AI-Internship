🚀 DecodeLabs AI Internship Projects

Welcome to my DecodeLabs AI Internship Project Repository.

This repository contains all the projects completed during the DecodeLabs Artificial Intelligence Internship. These projects focus on the practical implementation of AI concepts, Machine Learning, Recommendation Systems, and Optical Character Recognition (OCR) using Python.

The objective of these projects is to gain hands-on experience in developing intelligent systems, applying machine learning algorithms, building recommendation engines, and extracting text from images using OCR technology.


📂 Projects Included

🤖 Project 1: Rule-Based Chatbot

A Python-based chatbot that interacts with users using predefined rules and responses.

Features

- Personalized Greeting
- Interactive Menu System
- Mood Check-In
- Study Tips
- Fun Facts
- Motivational Quotes
- Session Statistics
- Continuous Conversation Loop
- Exit Option

AI Concept

Rule-Based Artificial Intelligence System



🌸 Project 2: Iris Flower Classification System

A Machine Learning project that classifies Iris flowers into different species using a Decision Tree Classifier.

Features

- Train-Test Split
- Decision Tree Model
- Accuracy Evaluation
- User Input Prediction

AI Concept

Machine Learning Classification

Features

- Interactive User Interface

Recommendation Systems
