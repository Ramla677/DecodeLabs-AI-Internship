Rule-Based Chatbot

Description

This project is a simple Rule-Based Chatbot developed using Python. The chatbot interacts with users through predefined commands and provides useful responses based on user input.

Features

- Personalized greeting
- Interactive menu system
- Mood check-in
- Study tips
- Fun facts
- Motivational quotes
- Session statistics
- Exit option

Technologies Used

- Python
- Random Module

How to Run

1. Open the project folder.
2. Open a terminal in the folder.
3. Run the following command:

python chatbot.py

Available Commands

- hi
- mood
- study tip
- fun fact
- motivate
- stats
- help
- exit

Sample Output

=======================================================

=======================================================

Hello Ramla! 👋
